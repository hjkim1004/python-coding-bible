# 🐍 Python 코딩 바이블 (Python Coding Bible)

> **"지루한 마크다운 문서 생성기를 넘어선, 오직 코딩테스트 합격만을 위한 가장 아름답고 지능적인 파이썬 바이블"**

이 저장소는 파이썬(Python)을 통해 코딩 테스트를 가장 효율적이고 시각적으로 아름답게 학습할 수 있도록 구성된 **초경량 인터랙티브 React 어플리케이션** 패키지입니다.  
Vercel/Linear 급의 미려한 **글래스모피즘 UI**와 **자가 진단 상호작용 퀴즈**, **실시간 진도율 트래킹 보드**가 탑재된 최고 품질의 온라인 바이블입니다.

│   │   │   ├── algo/          #   ├─ PART 2. 핵심 알고리즘 이론 8강
│   │   │   └── solve/         #   └─ PART 3. 기출문제 상세 해설집

│   └── vite.config.ts         # 광역 네트워크 수신 및 3000번 포트 강제 바인딩 설정

## 🚀 빠른 시작 가이드 (Quick Start)

### 1. 패키지 설치
터미널을 열고 `docs-app` 프로젝트 내부로 이동한 뒤, 아래 명령어로 필요한 자바스크립트 패키지를 설치합니다.
```bash
cd docs-app
npm install
```

### 2. 세련된 비법서 로컬 가동하기 (Port: 3000)
아래 명령어를 실행하여 초고속 Vite 로컬 개발 서버를 구동합니다.
```bash
npm run dev
```
- 브라우저를 열고 **[http://127.0.0.1:3000](http://127.0.0.1:3000)** 에 접속하시면 즉각 가동됩니다.
- 본인 컴퓨터 및 모바일, 동일 LAN 망 기기에서도 실시간으로 초고화질 학습서를 공유하여 보실 수 있습니다.

## 🎨 독파 효율을 올리는 프리미엄 기믹 명세

1.  **실시간 반응형 자가진단 퀴즈 (`QuizPanel` ❓)**:
    *   매 단원 설명 하단에 정교한 **"Self Checkup Quiz"**가 기본 탑재되어 있습니다. 
    *   선택지를 마우스로 누르면, 즉각적인 축하 메시지/에러 피드백과 함께 **"왜 이 답안이 오답인지"**에 대한 세부 행간 교습이 부드럽게 펼쳐집니다.
2.  **실시간 진도율 게이지 및 완독 체크박스 📈**:
    *   사이드바 각 레슨 오른쪽에 동그란 **체크 원형 단추**가 배치되어 있습니다.
    *   완독한 단원을 체크하면 상단 진도율 게이지 바가 **실시간으로 연동되어 % 가 증가**하며, 진도 상태는 컴퓨터(`localStorage`)에 완벽하게 박제 영구 보관됩니다.
3.  **지능형 아코디언 폴딩 목차 (`Collapsible Directory Tree` 📂)**:
    *   6대 필수 표준 라이브러리 목록이 평소에는 접혀 있어 사이드바를 단정하게 유지합니다. 
    *   개요를 클릭하거나 하위 단원(sys, heapq 등)을 공부할 때는 **화살표가 회전하며 하위 6대 트리가 입체적으로 스르륵 자동 전개**됩니다.
4.  **애플 감성의 macOS 듀얼 테마 코드 보드 (`CodeViewer` 💻)**:
    *   마우스 오버 시 입체적인 글로우 아웃라인 조명과 코코아 컬러의 복사 버튼, 체크 마크 Haptic 피드백이 가동됩니다.
    *   다크 테마에서는 시크한 제트블랙 카본 보드(`oneDark`), 라이트 테마에서는 화사한 은백색 메탈 보드(`oneLight`)로 코드 하이라이트가 적응형 실시간 스위칭됩니다!
